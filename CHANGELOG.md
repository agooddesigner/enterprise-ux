# Changelog

## 4.0.0 — Oct 2026
- **Intake step** before every design: look for a design system, ask ≤5 multiple-choice questions with recommended defaults (users & frequency, main job, data volume, roles, visual direction), or write an `Assumed:` block when nobody can answer.
- **Visual direction rebuilt as dials + presets**: 11 aesthetic dials, 12 presets (Soft bento, Dark precision, Blueprint, Restraint, Classic enterprise, Warm paper, Data-dense utility, Swiss, Expressive, Neubrutalism, Glass accents, Tactile), rules for mixing, a clash table, guard rails for layout experiments, 11 composition archetypes and AI-panel placements.
- The skill no longer assumes one look; Soft bento remains the house default only for overviews when nothing else decides.
- Ship gate gains Intake checks; new sources for visual research.
- Intake stops and asks (doesn't build in the same reply) when a whole screen is requested with 2+ unknowns, even if the host says to start immediately — fixed after the first v4 eval scored 0% on E10.
- Evals: E10–E13 (vague request, user away, existing design system, mixed style) and a design-system fixture.
